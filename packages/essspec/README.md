# essspec

Specs of ESS data-reduction workflows, and the bindings that compute them.
[docs/params.md](docs/params.md) is the guide to writing a spec, and [docs/bindings.md](docs/bindings.md) the guide to writing a binding.
Decisions about the spec are in [docs/developer/adr/](docs/developer/adr/), and the package split in [ADR 0007](../../docs/developer/adr/0007-packages-split-by-dependencies.md).
