# essbatch

Reduce many runs as batches: the command `essbatch` and a web page (extra `[web]`), on a workspace folder. A batch is a template and a table; each row of the table is one reduction. Publishing results to SciCat needs the extra `[scicat]`. It is built on [essapps](../essapps/README.md).

[docs/batch.md](docs/batch.md) is the guide for application developers. `essbatch --help` is the page for a person who operates batches. The [README of the page](src/ess/batch/web/README.md) says how to serve it.
